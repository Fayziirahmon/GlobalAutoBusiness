  - Balandligi: ~80-120px (kengligi ixtiyoriy)

  - Fayl bor bo'lsa   -> tasmada LOGO + NOM chiqadi
  - Fayl yo'q bo'lsa  -> faqat NOM chiqadi (sayt buzilmaydi)
